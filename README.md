# Flyzen PrintService

Программа для рабочего места склада: принимает этикетку от панели Flyzen и печатает её **без диалога браузера**. Из самой страницы тихая печать невозможна — `window.print()` всегда показывает диалог, поэтому печатает эта программа.

Работает на Windows. Слушает `http://127.0.0.1:19100`, наружу не открывается.

## Установка

1. Скачайте `printservice-win-x64.zip` из [релизов](https://github.com/WayupKG/flyzen-print-service/releases/latest) и распакуйте в любую папку — например, `C:\Flyzen\PrintService`.
2. Запустите `install.bat` — он пропишет автозагрузку и стартует программу.
3. В панели откройте меню под аватаром → **Настройки печати**, укажите `127.0.0.1` и `19100`, нажмите «Проверить подключение» и выберите принтер.

`uninstall.bat` останавливает программу и убирает её из автозагрузки.

## Окна у программы нет

Сервис работает в фоне: у exe оконная подсистема, поэтому терминал не открывается. Так задумано — раньше окно можно было закрыть, и печать молча переставала работать.

Что происходит, видно в `printservice.log` рядом с программой. Жив ли сервис, показывает кнопка «Проверить подключение» в панели. Повторный запуск безопасен: если порт уже занят своим же экземпляром, второй тихо завершается.

В архиве вместе с программой лежит `SumatraPDF.exe` (3.6.1) — им печатается PDF. Не удаляйте его из папки.

## Автозагрузка

Запись делается в ветку реестра текущего пользователя `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`. Прав администратора не требуется, и печать идёт из сеанса пользователя, где виден его принтер.

Этим занимаются `install.bat` и `uninstall.bat` — им консоль не нужна, в отличие от самой программы. Те же команды есть и у exe (`printservice autostart on|off|status`), но у собранной версии нет вывода в консоль, поэтому пользоваться ими стоит только при запуске из исходников.

## Другой порт

Аргументом или файлом `config.json` рядом с программой:

```
printservice --port 19200
```

```json
{ "port": 19200 }
```

Тот же порт нужно указать в настройках печати в панели.

## API

```
GET  /health   → { status, version, printers: ["Zebra ZD230", …] }
POST /print      { printer, format: "pdf", data, jobId }
               → { jobId, status: "printed" | "error", error? }
```

`data` — этикетка в base64 (PDF), как её отдаёт Warehouse API.

`jobId` обязателен: программа помнит последние 200 заданий и на повтор отвечает прежним результатом, ничего не печатая. Без этого ретрай после таймаута напечатал бы вторую этикетку. Ошибки печати не запоминаются — задание можно повторить.

Ответы содержат `Access-Control-Allow-Private-Network: true`. Без этого заголовка Chrome не пропускает запрос с https-страницы панели на localhost.

## Почему PDF, а не ZPL

Парк принтеров разный: Zebra говорит на ZPL, этикеточные Xprinter — на TSPL. Панель и бэкенд знают один формат, PDF, а разбираться с языками принтера — задача этой программы: она печатает через системный драйвер.

Если качество штрих-кода через драйвер окажется недостаточным, поле `format` уже заложено — для Zebra можно будет добавить приём `zpl`, не меняя панель.

## Разработка

```bash
npm start          # запуск из исходников
npm test           # тесты API (печать подменяется заглушкой)
```

На macOS и Linux программа запускается для отладки: список принтеров берётся из `lpstat`, печать идёт через `lp`. Автозагрузка настраивается только на Windows.

### Сборка exe

Нужен [Bun](https://bun.sh) — он умеет собирать Windows-бинарник и на другой ОС:

```bash
npm run build:win   # → dist/printservice.exe, ~94 МБ (рантайм внутри)
```

Вторым шагом скрипт вызывает `scripts/hide-console.mjs`: он переключает подсистему в заголовке PE с консольной на оконную. У Bun для этого есть `--windows-hide-console`, но флаг работает только при сборке на самой Windows — как и `--windows-title` с остальными метаданными. При кросс-компиляции их нельзя передать вовсе, поэтому правим два байта сами.

Для релиза сложите в архив `printservice.exe`, `SumatraPDF.exe` (portable-сборка с сайта проекта), `install.bat`, `uninstall.bat` и `INSTALL.txt` из папки `installer/` — в zip это ~46 МБ.
